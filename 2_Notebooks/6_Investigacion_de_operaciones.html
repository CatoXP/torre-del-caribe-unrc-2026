2. La frontera costo–tiempo¶

Un medio domina a otro si cuesta lo mismo o menos y tarda lo mismo o menos, y gana en al menos una de las dos. Los medios que nadie domina forman la frontera de Pareto: para ahorrar dinero hay que aceptar más tiempo. Solo esos son candidatos. El costo y el tiempo de un medio son la suma de sus tramos; si a un tramo le falta un dato, el medio queda incompleto y no se compara.

3. Programación lineal de dos variables: el método gráfico¶

Con los dos medios de la frontera (1 = el más barato, 2 = el más rápido) y $N$ viajeros de la campaña:

$$\min Z = c_1x_1 + c_2x_2 \quad \text{s.a.} \quad x_1 + x_2 \ge N, \qquad t_1x_1 + t_2x_2 \le \bar T\,N, \qquad x_1, x_2 \ge 0$$

  • $x_1, x_2$: viajeros que llegan por cada medio (variables de decisión).
  • $Z$: costo total del traslado (función objetivo).
  • Que lleguen todos y que el tiempo promedio no pase de $\bar T$ horas (restricciones).

El método: se dibujan las rectas, la región factible es la que cumple todo, se calculan sus vértices y se evalúa $Z$ en cada uno. Si hay óptimo, hay uno en un vértice (teorema fundamental de la programación lineal). Después se verifica con el simplex (PuLP/CBC), que también da el precio sombra: cuánto baja $Z$ si el viajero acepta una hora más de tiempo promedio.

import pulp

def resolver_grafico(c1, t1, c2, t2, N, T):
    rectas = {"llegan todos": (1, 1, N), "tiempo promedio": (t1, t2, T * N), "x1 = 0": (1, 0, 0), "x2 = 0": (0, 1, 0)}
    factible = lambda x1, x2: x1 >= -1e-7 and x2 >= -1e-7 and x1 + x2 >= N - 1e-7 and t1 * x1 + t2 * x2 <= T * N + 1e-7
    nombres, vertices = list(rectas), []
    for i in range(len(nombres)):
        for j in range(i + 1, len(nombres)):
            (a1, b1, r1), (a2, b2, r2) = rectas[nombres[i]], rectas[nombres[j]]
            det = a1 * b2 - a2 * b1
            if abs(det) > 1e-12:
                x1, x2 = (r1 * b2 - r2 * b1) / det, (a1 * r2 - a2 * r1) / det
                if factible(x1, x2):
                    vertices.append({"vértice": f"{nombres[i]} ∩ {nombres[j]}", "x1": x1, "x2": x2, "Z": c1 * x1 + c2 * x2})
    if not vertices:
        return None, None
    v = pd.DataFrame(vertices).drop_duplicates(["x1", "x2"]).sort_values("Z").reset_index(drop=True)
    m = pulp.LpProblem("transporte", pulp.LpMinimize)
    x = [pulp.LpVariable("x1", lowBound=0), pulp.LpVariable("x2", lowBound=0)]
    m += c1 * x[0] + c2 * x[1]
    m += (x[0] + x[1] >= N, "demanda"); m += (t1 * x[0] + t2 * x[1] <= T * N, "tiempo")
    m.solve(pulp.PULP_CBC_CMD(msg=False))
    assert abs(pulp.value(m.objective) - v.Z.iloc[0]) < 1e-6, "el simplex y el método gráfico no coinciden"
    return v, m.constraints["tiempo"].pi * N

def dibujar(c1, t1, c2, t2, N, T, v, titulo, nombre):
    fig, ax = plt.subplots(figsize=(6.4, 5))
    xs = np.linspace(0, 1.2 * N, 100)
    ax.plot(xs, N - xs, color=GUINDA, label="x1 + x2 = N (llegan todos)")
    ax.plot(xs, (T * N - t1 * xs) / t2, color=PALETA[2], label="t1·x1 + t2·x2 = T·N (tiempo promedio)")
    reg = v[["x1", "x2"]].to_numpy()
    centro = reg.mean(axis=0)
    reg = reg[np.argsort(np.arctan2(reg[:, 1] - centro[1], reg[:, 0] - centro[0]))]   # vértices en orden, sin cruzarse
    if len(reg) >= 3:
        ax.fill(np.r_[reg[:, 0], reg[0, 0]], np.r_[reg[:, 1], reg[0, 1]], color=DORADO, alpha=0.35, label="región factible")
    z = v.Z.iloc[0]
    ax.plot(xs, (z - c1 * xs) / c2, color=GRIS, ls="--", label=f"Z = {z:,.0f} (óptimo)")
    ax.scatter(v.x1.iloc[0], v.x2.iloc[0], s=90, color=GUINDA, zorder=4)
    ax.set_xlim(0, 1.2 * N); ax.set_ylim(0, 1.2 * N)
    ax.set_xlabel("x1: viajeros por el medio más barato"); ax.set_ylabel("x2: viajeros por el medio más rápido")
    ax.legend(frameon=False, fontsize=7); ax.set_title(titulo)
    guardar(fig, nombre)

4. Publicidad en un solo canal¶

El profesor pidió que, si se usan varios medios de publicidad, no intervenga la diversificación del presupuesto. Por eso elegimos un solo canal: el que trae cada visitante más barato.

$$p_c = \frac{\text{costo por clic}_c \times \text{pesos por dólar}}{\text{conversión}_c}$$

Los costos por clic y la conversión son de la categoría viajes de WordStream (2025), promedios de anunciantes de Estados Unidos usados como supuesto etiquetado. La conversión de Facebook para turismo no está publicada: el caso base usa la de Google.

5. El motor de la Torre: el dinero semana a semana¶

Cada semana, la Torre en vivo (que corre con Spark Structured Streaming, notebook 1) decide para cada lugar: temporada alta (no se gasta), fuera del plan, pausado (tormenta cerca, clima raro o llegó más gente de la esperada) o encendido. El dinero pausado no se pierde: pasa a la siguiente semana permitida.

$$b = \frac{\text{pesos del mes}}{\text{lunes del mes}}, \qquad \text{gasto}_w = \begin{cases} b + A_{w-1} & \text{si está encendido} \\ 0 & \text{si no} \end{cases}$$

    dias = pd.date_range(semana.replace(day=1), semana + pd.offsets.MonthEnd(0), freq="D")
